# IT-блог — курсовая работа

Полноценный сайт на чистом PHP с архитектурой MVC.

## Возможности

- Главная с последними статьями
- Список и просмотр статей с комментариями
- Редактирование статей и комментариев
- Калькулятор с рекурсивным парсером выражений

## Структура

| Файл | Назначение |
|---|---|
| `index.php` | Фронт-контроллер: автозагрузка, render(), роутинг |
| `Database.php` | Singleton-подключение к SQLite через PDO |
| `Calculator.php` | Класс калькулятора с рекурсивным разбором |
| `migrate.php` | Миграция БД и тестовые данные (запустить один раз) |
| `Controllers/` | HomeController, ArticlesController, CommentsController |
| `Views/` | Шаблоны страниц + общий `layout.php` |
| `style.css` | Стили интерфейса |
| `Пояснительная_записка.docx` | Отчёт по курсовой |

## Запуск

1. Открыть `migrate.php` один раз.
2. Открыть главную: `index.php`.

## Маршруты

| URL | Назначение |
|---|---|
| `/` | Главная |
| `/articles` | Все статьи |
| `/articles/{id}` | Просмотр статьи |
| `/articles/{id}/edit` | Редактирование статьи |
| `/articles/{id}/comments` | Добавление комментария (POST) |
| `/comments/{id}/edit` | Редактирование комментария |
| `/calculator` | Калькулятор |
