# Записная книжка — Лабораторная работа 5.1

PHP-сайт для хранения и управления контактами. Единственная точка входа — `index.php`.

---

## Файлы проекта

| Файл | Роль |
|------|------|
| `index.php` | Главный файл, открывается в браузере |
| `db.php` | Подключение к базе данных SQLite |
| `menu.php` | Функции генерации меню |
| `viewer.php` | Функция вывода таблицы контактов |
| `add.php` | Форма и логика добавления записи |
| `edit.php` | Форма и логика редактирования записи |
| `delete.php` | Список и логика удаления записи |
| `style.css` | Стили сайта |

---

## Архитектура

```
Браузер → index.php?action=view|add|edit|delete
               ├── db.php      (база данных, подключается всегда)
               ├── menu.php    (меню, подключается всегда)
               └── viewer / add / edit / delete .php (по action)
```

Нужный раздел определяется GET-параметром `?action=`. Все модули подключаются через `require_once` и не доступны напрямую в браузере.

---

## Описание функций

### `getDB()` — db.php

Возвращает объект `PDO` для работы с SQLite-базой данных.

- Использует паттерн Singleton через `static $db = null` — соединение создаётся только один раз за запрос.
- При первом вызове автоматически создаёт таблицу `contacts` если она ещё не существует (`CREATE TABLE IF NOT EXISTS`).
- `PDO::ATTR_ERRMODE_EXCEPTION` — при ошибке SQL бросает исключение, которое ловится через `try/catch`.
- `PDO::ATTR_DEFAULT_FETCH_MODE = FETCH_ASSOC` — строки возвращаются как массив `['поле' => 'значение']`.

**Структура таблицы `contacts`:**

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | уникальный номер |
| surname | TEXT NOT NULL | фамилия (обязательно) |
| name | TEXT NOT NULL | имя (обязательно) |
| lastname | TEXT | отчество |
| gender | TEXT | пол |
| date | TEXT | дата рождения |
| phone | TEXT | телефон |
| location | TEXT | адрес |
| email | TEXT | email |
| comment | TEXT | комментарий |

---

### `getMenu()` — menu.php

Возвращает строку с HTML-ссылками главного меню для вставки внутрь `<header>`.

- Читает `$_GET['action']` — определяет активный пункт.
- Активному пункту присваивается CSS-класс `select` → красный цвет.
- Если `action` не передан или неизвестен — активным считается "Просмотр".

Генерирует 4 ссылки: Просмотр / Добавление записи / Редактирование записи / Удаление записи.

---

### `getSortMenu()` — menu.php

Возвращает строку с HTML-блоком `<div class="submenu">` — подменю сортировки.

- Вызывается из `index.php` только при `action=view`.
- Читает `$_GET['sort']` — определяет активный вариант сортировки.
- По умолчанию (`sort=id`) — сортировка по порядку добавления.

Генерирует 3 ссылки: По порядку добавления / По фамилии / По дате рождения.

---

### `getViewer(string $sort, int $page)` — viewer.php

Принимает параметры сортировки и номер страницы, возвращает строку с HTML-таблицей и пагинацией.

**Пагинация:**
```
$offset = ($page - 1) * $perPage   // страница 2 → пропустить первые 10 записей
$totalPages = ceil($total / 10)    // 25 записей → 3 страницы
```
В SQL: `LIMIT 10 OFFSET $offset` — выбрать только 10 записей начиная с нужной.
Если страниц больше 1 — выводится блок ссылок с номерами страниц.

**Защита от SQL-инъекции:**
- `$order` подставляется в строку запроса, но только из заранее проверенного словаря `$orderMap`.
- `LIMIT` и `OFFSET` передаются через `bindValue(..., PDO::PARAM_INT)`.

### add.php

Выполняется при подключении через `require_once`. Функций не содержит.

1. Если метод запроса `POST` и нажата кнопка — считать данные из `$_POST`.
2. `trim()` убирает пробелы по краям каждого поля.
3. Если фамилия и имя не пусты — выполнить `INSERT INTO contacts`.
4. Запрос выполняется через `prepare` + `execute` с именованными параметрами — защита от SQL-инъекции.
5. Вывести сообщение: зелёное "Запись добавлена" или красное "Ошибка: запись не добавлена".
6. Всегда показать пустую форму заново.

---

### edit.php

Выполняется при подключении через `require_once`. Функций не содержит.

1. Загрузить список всех контактов, отсортированных по фамилии, затем по имени — для боковой панели.
2. Определить текущую запись: из `$_GET['id']` или первая по алфавиту.
3. Если метод `POST` — выполнить `UPDATE contacts SET ... WHERE id=:id` и обновить `$currentId`.
4. Загрузить данные текущей записи для предзаполнения формы.
5. Вывести боковую панель: текущая запись получает класс `currentRow` (выделение цветом).
6. Вывести форму с полями, заполненными значениями из базы данных.
7. `id` текущей записи передаётся через скрытое поле `<input type="hidden" name="id">`.

---

### delete.php

Выполняется при подключении через `require_once`. Функций не содержит.

1. Если в URL есть `?id=N`:
   - Сначала загрузить фамилию записи (`SELECT surname WHERE id=N`).
   - Выполнить `DELETE FROM contacts WHERE id=:id`.
   - Вывести сообщение: "Запись с фамилией Иванов удалена".
2. Загрузить актуальный список контактов (уже без удалённой записи).
3. Вывести список ссылок в формате "Фамилия И.О.".

`mb_substr($str, 0, 1, 'UTF-8')` — безопасное получение первой буквы кириллического слова (обычный `substr` режет многобайтные символы).

## Безопасность

| Угроза | Защита |
|--------|--------|
| SQL-инъекция через форму | `prepare()` + `execute()` с именованными параметрами |
| SQL-инъекция через сортировку | whitelist-словарь `$orderMap`, произвольная строка не попадает в запрос |
| XSS через вывод данных | `htmlspecialchars()` на каждом выводимом значении из БД |
| Произвольный `action` в URL | `in_array()` проверка перед использованием |

## Инструкция для сдачи зачёта

### Что показывать

**1. Просмотр** — открыть сайт, показать таблицу. Активный пункт меню красный, остальные синие.

**2. Добавление** → "Добавление записи":
- Заполнить все поля и нажать кнопку.
- Показать зелёное сообщение "Запись добавлена".
- Добавить 2–3 записи (нужны для демонстрации сортировки и пагинации).

**3. Сортировка** — вернуться в "Просмотр":
- Переключить все три варианта сортировки, показать что таблица меняется.
- При записях > 10 показать пагинацию и переход по страницам.

**4. Редактирование** → "Редактирование записи":
- Показать боковой список (отсортирован по алфавиту).
- Кликнуть по записи — форма заполняется, запись выделяется цветом.
- Изменить поля, нажать "Сохранить", показать "Запись обновлена".

**5. Удаление** → "Удаление записи":
- Показать список в формате "Фамилия И.О."
- Кликнуть — показать "Запись с фамилией Иванов удалена".

### Вопросы на зачёте

**— Почему все страницы через index.php?**

По заданию только `index.php` доступен через браузер. Остальные — модули, подключаемые через `require_once`. Раздел определяется параметром `?action=` в URL.

**— Что такое PDO и зачем prepare/execute?**

PDO — PHP-класс для работы с базами данных. `prepare` создаёт шаблон запроса с заглушками вместо данных, `execute` безопасно подставляет данные. Пользователь не может вставить свой SQL через поля формы.

**— Зачем `static $db = null` в getDB()?**

Чтобы создавать соединение с БД только один раз за запрос. При повторном вызове `getDB()` возвращает уже созданный объект. Это паттерн Singleton.

**— Зачем `htmlspecialchars()` при выводе?**

Без него пользователь мог бы сохранить в поле `<script>alert(1)</script>` и при выводе на странице этот скрипт выполнился бы в браузере другого пользователя (XSS-атака).

**— Почему сортировка через $orderMap, а не напрямую `ORDER BY $_GET['sort']`?**

Потому что `ORDER BY` нельзя защитить через `prepare` — это часть структуры запроса, а не данные. Поэтому значение из URL проверяется по whitelist-словарю. Произвольная строка туда не попадёт.

**— Как работает пагинация?**

`SELECT COUNT(*)` считает общее количество записей, `ceil(total / 10)` даёт количество страниц. В SQL: `LIMIT 10 OFFSET N`, где `N = (страница − 1) × 10`. Страница 3 → `OFFSET 20` → пропустить 20 записей.

**— Почему `mb_substr` а не `substr`?**

Кириллические символы в UTF-8 занимают 2 байта. `substr` работает с байтами и разрежет букву пополам. `mb_substr(..., 'UTF-8')` работает с символами корректно.
